# Coaching examples

`labeled_answers.csv` contains the existing labeled seed. `synthetic_answers.csv`
is generated by `../generate_synthetic.py`; it is a bootstrap dataset, not real
candidate validation. `../feature_extractor.py` defines the canonical nine-field
schema and `../test_features.py` checks stored text-derived values against it.

Do not add private interview transcripts without explicit consent and a reviewed
retention/annotation process. See [ML guide](../README.md) for evaluation limits.
