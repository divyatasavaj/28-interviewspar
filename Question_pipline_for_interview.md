# Question Pipeline for Interview

## Overview
This document outlines the question pipeline structure for conducting interviews.

## Stages

### 1. Screening
- Basic qualification check
- Resume review
- Initial fit assessment

### 2. Technical Assessment
- Coding challenges
- System design questions
- Domain knowledge evaluation

### 3. Behavioral Interview
- Past experience discussion
- Problem-solving approach
- Team collaboration examples

### 4. Final Round
- Leadership assessment
- Cultural fit evaluation
- Offer discussion

## Question Categories
- **Technical**: Algorithms, Data Structures, System Design
- **Behavioral**: STAR method questions
- **Situational**: Hypothetical scenarios
- **Domain-specific**: Role-relevant expertise

## Evaluation Criteria
- Technical competency
- Communication skills
- Problem-solving ability
- Cultural alignment
